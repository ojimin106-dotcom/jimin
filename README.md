# 꽃말 우체국 · FLOWER POST

직접 쓴 편지와 꽃말을 담은 꽃을 함께 보내는 가상 꽃집 '꽃말 우체국'의 홈페이지입니다. (수업 과제)

## 페이지 구성 (29쪽)
| 메뉴 | 파일 | 상세페이지 |
|---|---|---|
| 홈 | `index.html` | 홍보 영상, 마음별 바로 주문 |
| 브랜드 이야기 | `about.html` | |
| 이용 안내 | `how.html` | 주문 과정, 배송·픽업, 자주 묻는 질문 |
| 상품 | `shop.html` | `product-letter.html`, `product-mini.html`, `product-bouquet.html` |
| 선물 가이드 | `gift.html` | `gift-lover.html`, `gift-mom.html`, `gift-friend.html` |
| 꽃말 사전 | `flowers.html` | `flower-*.html` 11종 |
| 홍보 영상 | `media.html` | 홍보 영상 30초, 숏폼 3편, 홈페이지 QR 코드 |
| 주문하기 | `checkout.html` | `success.html`, `fail.html` |
| 꽃다발 조합기 | `bouquet-app.html` | 이전 버전 홈페이지의 조합기 |

## 과제 요구사항 반영
- 메뉴마다 서로 다른 페이지, 상세페이지 17쪽
- 메뉴는 스크롤해도 항상 화면 위에 고정 (휴대폰에서는 옆으로 밀어서 보기)
- 마음 버튼 한 번에 주문서가 열리고, 주문서와 결제가 한 페이지에서 끝남
- 컴퓨터 · 태블릿 · 휴대폰 반응형
- 토스페이먼츠 결제위젯 테스트 결제 (실제로 돈이 빠져나가지 않음)

## 폴더
```
assets/css, assets/js, assets/img   새 홈페이지 스타일 · 스크립트 · 그림
media/                              홍보 영상 · 숏폼 (mp4)
assets/*.jpg, fonts/                꽃다발 조합기 페이지용 이미지 · 글꼴
```

## 안내
- 가상 브랜드이며 실제 판매 정보가 아닙니다. 로고 · 이미지 · 영상은 AI(Claude) 생성물입니다.
- 결제 키는 토스페이먼츠 문서에 공개된 테스트 키입니다. 실제 판매 시 본인 상점 키와 서버 승인 처리가 필요합니다.
- 꽃말 출처: 시대일보(2014.2.6 / 2014.10.2) 농식품부·농진청 '이달의 꽃' 프리지아·리시안셔스. 그 밖의 꽃말은 일반적으로 알려진 꽃말이며 자료마다 다를 수 있습니다.
