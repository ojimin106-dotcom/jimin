# 꽃말 우체국 · FLOWER POST

마음을 꽃말로 번역해 편지와 함께 보내는 가상 꽃집 '꽃말 우체국'의 소개 홈페이지입니다.
홈페이지 안에 **꽃말 꽃다발 조합기**가 들어 있어, 전하고 싶은 말을 적으면 꽃말에 맞는 꽃다발 조합을 추천해 줍니다.

## 주요 기능
- 브랜드 소개, 차별점, 이용 방법, 첫 게시물 3컷
- 꽃말 꽃다발 조합기: 전하고 싶은 말 · 상황(사랑 고백·생일·이별 ·재회 등 24가지) · 마음 · 받는 사람 · 구성을 고르면 조합 A·B·C 추천, 꽃다발 그림, 편지 미리보기, DM 문구 복사
- 주문서 & 체험용 결제: 편지 문구·실링 왁스 색·배송 정보 입력, 결제 수단 선택, 금액 자동 계산, 주문 완료 화면 (실제 결제·배송은 되지 않음)
- 꽃말 사전: 꽃 40종 검색, 눌러서 조합기에 담기

## 파일 구성
```
index.html          홈페이지 + 앱 (HTML · CSS · JavaScript 한 파일)
assets/             로고·사진 이미지
fonts/              한글 글꼴 (인터넷 없이도 글씨가 깨지지 않게)
.nojekyll           GitHub Pages 설정 파일
```

## 안내
- 수업 과제로 만든 가상 채널이며 실제 판매 정보가 아닙니다.
